# Iron Bridge Mobility Solutions

Marketing and lead-generation website for Iron Bridge Mobility Solutions — medical courier
and commercial logistics services throughout Maryland, Washington DC, and Northern Virginia.

Built on Next.js (App Router) + TypeScript + Tailwind CSS, starting from the
[next-saas-lp](https://github.com/benlhachemi/next-saas-lp) template (MIT-licensed; see
`THIRD_PARTY_NOTICES.md`) and being reworked into the Iron Bridge site.

## Development

```bash
yarn
yarn dev # http://localhost:3000
```
